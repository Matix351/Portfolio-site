# Polish screenshot originals

These ten unmodified source screenshots are preserved for future Polish-language support.
Each `<name>-PL.png` corresponds to the English-translated `../<name>.png` used by the current page.

The English copies are AI-assisted translations approved for use on the English page. The Polish originals were copied and hash-verified before replacing the displayed assets.

When adding a Polish locale, use `images/mobile-commerce/pl/<name>-PL.png` for these screenshots. No language switcher is implemented by this asset change.
